# Predictive Modeling and Risk Scoring for Bank Customer Churn

## Contents
- `Churn_Modelling.csv` — source dataset (10,000 bank customers)
- `pipeline.py` — full pipeline: preprocessing, feature engineering, 5-model
  training (Logistic Regression, Decision Tree, Random Forest, Gradient
  Boosting, XGBoost), evaluation, and SHAP/PDP explainability. Writes all
  outputs to `artifacts/`.
- `app.py` — Streamlit dashboard with 4 modules: Churn Risk Calculator,
  Probability Distribution, Feature Importance, What-If Simulator.
- `artifacts/` — trained models, metrics, feature importances, and figures
  generated by `pipeline.py` (already run once — `app.py` loads these directly).
- `requirements.txt` — Python dependencies.

## Run it
```bash
pip install -r requirements.txt

# Re-run the full modeling pipeline (optional — artifacts/ is already populated)
python pipeline.py

# Launch the dashboard
streamlit run app.py
```

## Results
Best model: **Gradient Boosting** — Accuracy 87.1%, ROC-AUC 0.869
(5-fold CV mean 0.864). Top churn drivers: number of products held,
customer age, account activity/engagement, zero-balance status, geography.

## Deploy (Streamlit Community Cloud, free)
1. Push this folder's contents to the root of a GitHub repo (`app.py`, `requirements.txt`,
   `Churn_Modelling.csv`, and `artifacts/` must all be at the repo root).
2. Go to https://share.streamlit.io, sign in with GitHub, click **Create app**.
3. Pick the repo, branch `main`, main file `app.py`. Under **Advanced settings** choose Python 3.13
   (the version the pinned `requirements.txt` was tested on), then **Deploy**.
4. First build takes a few minutes. The app URL looks like `https://<name>.streamlit.app`.

If the build fails on a library version, re-run `python pipeline.py` locally with the same
versions you deploy with and commit the regenerated `artifacts/` — the saved model files must be
created with the same scikit-learn version the app loads them with.
